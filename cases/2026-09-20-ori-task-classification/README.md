## 应用场景与价值

把传入请求分成 30 种任务，比较五个模型的速度、费用和正确性。

**可借鉴点（分析）**：相比只展示快慢的短片，披露了任务、样本数、合成来源和部分配置，也说明 Jev 不是最便宜的模型。

## 输入、操作与输出

OpenRouter 说明五模型在相同 200 条合成案例上依次、无状态测试；LLM 关闭推理，GLM 5.3 Flash 除外，使用低推理力度。

没有披露的提示词、状态格式、阈值或失败恢复逻辑保持未知。应用按作者演示收录，不认定已稳定上线。
