## 用人话解释原理

给注释两张成绩单：一句话可以正确复述代码，却没有解释为什么这样写；另一句话则可能连代码做什么都说错。Jev 分别评分，帮助开发者找到值得复核的注释。

## 应用场景与价值

分别检查注释有没有说错，以及它是否提供了代码之外的有用信息。

**可借鉴点（分析）**：把事实正确与信息价值拆开，比单一代码总分更容易看出问题；与 ESLint 规则实验同属局部代码判断，但这里评的是注释质量，不是规则是否合规。
