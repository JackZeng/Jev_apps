## 应用场景与价值

给边界样例标注对错，让工具逐轮改进 Jev 的判断说明。

**可借鉴点（分析）**：比直接凭感觉写提示多了反馈、差异检查和回退；支持二分类、多分类、多标签及有序评分。

## 输入、操作与输出

固定版本 CLI 挑选不确定样例与随机审计样本；GEPA 用人工标签优化任务说明，由独立的反思模型提出修改。这是提示与规则优化，不是微调 Jev 权重。

没有披露的提示词、状态格式、阈值或失败恢复逻辑保持未知。应用按作者演示收录，不认定已稳定上线。
