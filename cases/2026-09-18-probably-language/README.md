## 应用场景与价值

把“这封邮件是否紧急”这样的判断写进条件分支，再让文字模型按结果起草回复。

**可借鉴点（分析）**：把分类、分支和改写循环放进可读的小语言，方便理解 Jev 与生成模型怎样协作；可与词表聊天、RISC-jeV 的组合实验对照。

## 输入、操作与输出

官网 Probably 0.1 说明：TypeScript 解释器执行程序，feels 调用 Jev 做条件判断，match 选择描述对应分支，while 可重复判断；llm 调用独立文字模型。条件判断可配置置信门槛，match 在该版本没有置信门槛。

没有披露的提示词、状态格式、阈值或失败恢复逻辑保持未知。应用按作者演示收录，不认定已稳定上线。
