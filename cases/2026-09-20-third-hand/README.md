## 应用场景与价值

读取应用控件，按指令点击，并输入指令中已有的文字。

**可借鉴点（分析）**：比 Ultrafast 的小型 LLM 填字路径更受限，但无需额外生成模型；与只点击的 TipTour 相比可输入明确给出的文本。

## 输入、操作与输出

固定版代码读取无障碍控件，必要时用 Apple Vision 本地 OCR；Jev 选择动作及从用户请求提取的候选文本，执行后检查状态。屏幕像素不上传，但任务、标签和值会发给 TypeSafe。

没有披露的提示词、状态格式、阈值或失败恢复逻辑保持未知。应用按作者演示收录，不认定已稳定上线。
