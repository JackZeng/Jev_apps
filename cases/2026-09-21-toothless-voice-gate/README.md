## 应用场景与价值

区分对助手说的话和人与人之间的交谈，减少无关插话。

**可借鉴点（分析）**：与 CNVS 同属免唤醒词交互；Toothless 更强调多人交谈中的接话时机。

## 输入、操作与输出

作者描述 Jev 同时考虑话题延续、是否需要联网及助手是否能帮忙等条件；语音转文字、说话人信息和最终唤醒规则未完整披露。
