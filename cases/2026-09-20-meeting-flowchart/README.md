## 应用场景与价值

从会议发言中筛出业务步骤，逐步画进可编辑的流程图。

**可借鉴点（分析）**：比单纯给访谈记录打分更直接地产生可修改的工作草稿；判断、文字整理和画图职责清楚。

## 输入、操作与输出

作者描述：逐句判断是否涉及业务及新增/修改/删除/无操作；置信度至少 50% 才交给 LLM 整理步骤，再用 Jev 检查依据、重复和负责人，代码写入 draw.io。

没有披露的提示词、状态格式、阈值或失败恢复逻辑保持未知。应用按作者演示收录，不认定已稳定上线。
