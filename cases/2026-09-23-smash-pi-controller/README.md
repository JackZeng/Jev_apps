## 应用场景与价值

用采集卡读游戏画面，让 Jev 选择招式，再由硬件操作手柄。

**可借鉴点（分析）**：把观察、选择和实体输入连起来，可研究硬件延迟的影响。

## 输入、操作与输出

前帖说明 Pi 5 控制手柄、OpenCV 检测画面；新帖称 Jev 每秒选招 2–3 次，会按距离和方向出招。

没有披露的提示词、状态格式、阈值或失败恢复逻辑保持未知。应用按作者演示收录，不认定已稳定上线。
