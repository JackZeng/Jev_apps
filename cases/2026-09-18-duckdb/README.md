## 应用场景与价值

在分析表格时，顺手让 Jev 给每行文字分个类。

**可借鉴点（分析）**：可以保留 SQL 数据分析流程，比手动导出文本更方便。

## 输入、操作与输出

表格数据进入 DuckDB 扩展，扩展调用 Jev 分类并返回可查询结果。
