## 应用场景与价值

识别税务 PDF 每页属于哪种表格，给后续整理提供标签。

**可借鉴点（分析）**：比泛用文件整理更明确：有 261 种表格覆盖说明、公开测试计数和拒绝条件。

## 输入、操作与输出

固定版本文档先用 pdftotext 提取文本，再在表格与页面类型候选中分类；企业表格有后续问题，默认置信度门槛 0.95，空白文本跳过模型。

没有披露的提示词、状态格式、阈值或失败恢复逻辑保持未知。应用按作者演示收录，不认定已稳定上线。
