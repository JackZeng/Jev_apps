## 应用场景与价值

让摄像头和麦克风感知到的内容，影响画面的灯光与特效。

**可借鉴点（分析）**：将本地感知与语义决策分离，适合实时交互媒体。

## 输入、操作与输出

摄像头/麦克风 → Moonshine、YOLO26、DepthART → Jev → 灯光、阴影、bloom；ruNNtime 与 TypeGPU 共享 GPU 资源。

没有披露的提示词、状态格式、阈值或失败恢复逻辑保持未知。应用按作者演示收录，不认定已稳定上线。
