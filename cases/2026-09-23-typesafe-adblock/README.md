## 应用场景与价值

先找像广告的网页元素，再判断是否移除或高亮。

**可借鉴点（分析）**：能结合文本含义判断候选，与 Unclutter 的一般页面清理同类比较。

## 输入、操作与输出

启发式规则提取候选 DOM 和短描述，Jev 批量 Noul 判断；默认概率 ≥0.70 后执行，监听后续页面变化。

没有披露的提示词、状态格式、阈值或失败恢复逻辑保持未知。应用按作者演示收录，不认定已稳定上线。
