## 应用场景与价值

把界面需求变成受约束的组件布局，支持增删和移动组件。

**可借鉴点（分析）**：比逐字符输出更容易约束结构；相对像素绘图，输出可交互的组件树，结构错误可由代码拦截。

## 输入、操作与输出

项目文档说明第一批判断选择组件和数量，第二批安排父子关系与顺序；代码生成并验证 JSON。使用应用提供的 17 类组件、绑定与动作，不是预制整页模板，也不依赖另一个生成模型写 JSON。

没有披露的提示词、状态格式、阈值或失败恢复逻辑保持未知。应用按作者演示收录，不认定已稳定上线。
