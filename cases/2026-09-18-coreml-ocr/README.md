## 用人话解释原理

本地识别程序负责“看屏幕”，把按钮上的文字列出来；Jev 负责从列表里做选择。图片留在本机，但识别出的文字仍会发给 Jev。

## 应用场景与价值

先在 Mac 上认出按钮和文字，再让 Jev 选要点击的位置。

**可借鉴点（分析）**：无需 DOM，作者称屏幕像素留在 Mac；有利于覆盖原生应用。

## 输入、操作与输出

本地 CoreML 分割界面元素 → OCR 读标签 → Jev 对元素给概率 → 点击后重新检测。

没有披露的提示词、状态格式、阈值或失败恢复逻辑保持未知。应用按作者演示收录，不认定已稳定上线。
