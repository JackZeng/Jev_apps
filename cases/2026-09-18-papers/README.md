## 应用场景与价值

把一千多篇 AI 论文分门别类，方便按主题浏览。

**可借鉴点（分析）**：清楚分离生成和分类成本，适合资料目录和研究索引。

## 输入、操作与输出

DeepSeek V4 Flash 生成摘要 → 标题、摘要及候选主题送入 Jev → 分类供网站可视化。

没有披露的提示词、状态格式、阈值或失败恢复逻辑保持未知。应用按作者演示收录，不认定已稳定上线。
