## 应用场景与价值

把朗读转成文字，标出漏词和可疑替换，辅助练习。

**可借鉴点（分析）**：有逐词反馈和明确分工，比只显示转录更适合自查漏读。

## 输入、操作与输出

R2T2 做语音识别，代码对齐词语；Jev 判断可疑词是否等价、错误类别和语义一致性。本地公式计算完整度、节奏和总分。

没有披露的提示词、状态格式、阈值或失败恢复逻辑保持未知。应用按作者演示收录，不认定已稳定上线。
