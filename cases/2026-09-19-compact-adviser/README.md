## 应用场景与价值

在编码会话接近合适停顿点时，提示是否该整理上下文。

**可借鉴点（分析）**：补充已有工具输出压缩的上游环节：先选择时机，再由宿主执行；公开门槛与回退说明便于检查。

## 输入、操作与输出

固定版本文档用两个是非问题判断工作单元是否结束、当前属于动手还是协调阶段；代码结合上下文占用率、最小 token 数和冷却条件决定提示。Pi、Claude 可选自动模式，Codex CLI 仅提示。

没有披露的提示词、状态格式、阈值或失败恢复逻辑保持未知。应用按作者演示收录，不认定已稳定上线。
