## 应用场景与价值

让四个模型给一组邮件分类，在同一页面对照完成进度和耗时。

**可借鉴点（分析）**：比单模型批量演示更直观地展示不同模型处理同类任务的等待差异；可与 500 封邮件分类案例对照，分别观察跨模型响应和批量吞吐。

## 输入、操作与输出

原帖视频的 JEV Speed Race 界面并排显示 Jev、GPT Luna、Claude Sonnet、Gemini 3.5 Flash，展示相同的邮件行、完成进度和计时。由此可确认任务级速度对照；调用参数、完整模型版本与分类规则尚未核清。

没有披露的提示词、状态格式、阈值或失败恢复逻辑保持未知。应用按作者演示收录，不认定已稳定上线。
