## 应用场景与价值

让 Jev 看价格变化后选买或卖，再由程序把订单送出去。

**可借鉴点（分析）**：决策到外部执行的链路清晰，适合研究事件驱动系统。

## 输入、操作与输出

资产对价格流 → Jev 选 buy / sell → Monad 上的 Kuru 订单簿执行。
