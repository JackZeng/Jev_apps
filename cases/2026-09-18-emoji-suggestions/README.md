## 应用场景与价值

输入文字时，自动推荐与意思相符的 emoji。

**可借鉴点（分析）**：输出范围有限、容易展示；相比字符聊天的长循环，更适合把一次判断直接变成界面反馈。

## 输入、操作与输出

演示将输入文字映射到 emoji 候选和分数；作者比较 3 个与 200 个候选时的响应。API 原语、缓存与请求策略未公开。

没有披露的提示词、状态格式、阈值或失败恢复逻辑保持未知。应用按作者演示收录，不认定已稳定上线。
