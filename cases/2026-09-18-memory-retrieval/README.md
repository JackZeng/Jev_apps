# 记忆系统检索筛选

**简体中文** | [English](README.en.md)

> 从 AI 记忆库里筛出真正相关的内容，减少翻找和阅读负担。

## 用人话解释原理

先找到一批可能相关的记忆，再由 Jev 做第二轮筛选。像从搜索结果里挑重点；筛得太狠，也可能漏掉关键线索。

## 应用场景与价值

从 AI 记忆库里筛出真正相关的内容，减少翻找和阅读负担。

**可借鉴点（分析）**：聚焦检索后的内容筛选，可与现有记忆系统组合。
