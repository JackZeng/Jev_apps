## 用人话解释原理

像从菜单点菜：Jev 只能选程序事先列出的动作编号。程序检查编号后才操作，并另查表单是否填写成功；当前公开示例还不是“看截图操作任意软件”。

## 应用场景与价值

给 Jev 一份允许执行的网页操作清单，让它选一个，再检查是否做对。

**可借鉴点（分析）**：动作候选由本地程序掌控并验证，有 Python/TypeScript 预览和独立结果检查。

## 输入、操作与输出

当前 PR #3916 说明：应用读取 DOM/语义信息，构造完整动作候选，Jev 只选候选 ID；本地校验后执行 Driver 动作，并通过独立状态端点验证表单结果。

没有披露的提示词、状态格式、阈值或失败恢复逻辑保持未知。应用按作者演示收录，不认定已稳定上线。
