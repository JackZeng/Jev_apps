## 应用场景与价值

一边聊天一边推荐商品，让虚拟店员的表情跟着对话变化。

**可借鉴点（分析）**：将推荐放进实时对话，适合探索边说边选的购物体验；比离线意图标签更接近面向顾客的交互。

## 输入、操作与输出

作者使用 Jev 与 gpt-live-1，在对话过程中根据用户发言更新商品推荐，并按内容切换头像表情。语音处理、推荐排序及表情映射的具体职责划分未公开。

没有披露的提示词、状态格式、阈值或失败恢复逻辑保持未知。应用按作者演示收录，不认定已稳定上线。
