# 本地编码代理分工

**简体中文** | [English](README.en.md)

> 把简单活、复杂问题和长时间编程任务分给不同的 AI 助手。

## 用人话解释原理

程序在分派任务前先问 Jev 应该交给谁，再按预设路径调用助手。这样能把“选择助手”和“完成任务”分开处理。

## 应用场景与价值

把简单活、复杂问题和长时间编程任务分给不同的 AI 助手。

**可借鉴点（分析）**：可把机械任务、复杂推理和长实现任务分开。

## 输入、操作与输出

在委派流程加入确定性 hook，由 Jev 判断任务应交给哪个 harness / model。

没有披露的提示词、状态格式、阈值或失败恢复逻辑保持未知。应用按作者演示收录，不认定已稳定上线。
