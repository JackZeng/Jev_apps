## 应用场景与价值

快速检查一批代码修改有没有泄密、删测试等风险，不确定时交给人复核。

**可借鉴点（分析）**：检查项和升级规则明确，比单个“代码好不好”评分更易检查。

## 输入、操作与输出

diff → 一次 Jev 请求返回 14 项概率 → 代码生成结论；关键项在 0.35–0.65 时交给人或大模型。

没有披露的提示词、状态格式、阈值或失败恢复逻辑保持未知。应用按作者演示收录，不认定已稳定上线。
