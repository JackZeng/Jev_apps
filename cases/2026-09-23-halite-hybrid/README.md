## 应用场景与价值

比较纯语言模型和大模型规划加 Jev 执行的策略游戏方案。

**可借鉴点（分析）**：有纯模型和混合方案，也保留对 Jev 不利的后续结果。

Halite 2 中 GLM 5.3 Flash 负责星球、扩张、战斗和重规划，Jev 负责逐船操作；后续 Halite 1 比较 Jev 与 OpenJev 执行层。
