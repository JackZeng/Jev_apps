## 应用场景与价值

根据工作区已有标签整理笔记，把不确定的匹配留给人确认。

**可借鉴点（分析）**：保留用户自己的标签体系；相较 Shiori 的网页书签，Kaku 面向笔记库整理。

## 输入、操作与输出

作者说明 Jev 按现有标签批量判断；高置信结果可应用，低置信结果在矩阵中复核，并提供差异确认、丢弃和快照回退。

没有披露的提示词、状态格式、阈值或失败恢复逻辑保持未知。应用按作者演示收录，不认定已稳定上线。
