## 应用场景与价值

检查代码是否符合行为约定，把可疑缺陷排出来供人或代理复查。

**可借鉴点（分析）**：能检查普通语法规则难表达的行为要求，比只给注释打分更贴近实现。

## 输入、操作与输出

tree-sitter 建立方法与调用图，Jev 用 Noul、Choice、Score 判断缺陷、位置和严重性；自然语言 ensure 规则可并入检查，修改后可再次核对。

没有披露的提示词、状态格式、阈值或失败恢复逻辑保持未知。应用按作者演示收录，不认定已稳定上线。
