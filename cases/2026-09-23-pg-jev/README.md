## 应用场景与价值

在 PostgreSQL 查询中写语义条件，对每行做分类、评分或筛选。

**可借鉴点（分析）**：与 DuckDB 同为 SQL 集成，但面向 PostgreSQL，支持把判断组合进普通查询。

## 输入、操作与输出

扩展把多行打包进共享状态，为各行建立问题；默认每批 20 行，会话内按行内容缓存答案，并提供概率、类别和评分函数。

没有披露的提示词、状态格式、阈值或失败恢复逻辑保持未知。应用按作者演示收录，不认定已稳定上线。
