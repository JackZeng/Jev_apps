## 应用场景与价值

筛掉搜索结果中的无关内容和近似重复，减少助手要读的材料。

**可借鉴点（分析）**：面向多网页研究，和只在当前网页划出原句的 Needle 互补；代码与小规模评测可检查。

## 输入、操作与输出

搜索服务取回结果，程序去除相同链接或标题，Jev 评相关性并确认近似重复；可选抓网页、分块筛选，另一个模型负责可选摘要。

没有披露的提示词、状态格式、阈值或失败恢复逻辑保持未知。应用按作者演示收录，不认定已稳定上线。
