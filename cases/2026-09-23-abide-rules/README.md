## 应用场景与价值

按项目指令检查代码修改，并把可疑违规反馈给编码代理。

**可借鉴点（分析）**：相比普通语法检查，可表达别过度抽象等语义规则，并公开误报分析。

## 输入、操作与输出

把指令编成规则，在编辑或回合结束时将规则与 diff 交给 Jev；按概率分档提示或要求修正，超时/无网络则放行并记漏检。

没有披露的提示词、状态格式、阈值或失败恢复逻辑保持未知。应用按作者演示收录，不认定已稳定上线。

## 原理拆解与同类比较

回放评测不验证代理是否真的修好；复核者是 Claude，并非独立人工实验。单次编辑误报很多，不能保证抓住每次违规。

同类逐项对比、公共流程和建议实验见 [专题分析](../../breakdowns/2026-09-18-review.md)。实现说明来自作者公开材料；优势及尚缺证据属于本仓库分析，不能视为模型内部架构已被证实。
