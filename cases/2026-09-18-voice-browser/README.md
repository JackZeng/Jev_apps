# 语音控制浏览器

**简体中文** | [English](README.en.md)

> 说出指令，让浏览器替你点击，例如“返回上一页”。

## 用人话解释原理

先把声音转成文字，再让 Jev 判断指令对应哪个操作，最后由浏览器执行。Jev 在这里负责理解并选择动作，不负责听声音。

## 应用场景与价值

说出指令，让浏览器替你点击，例如“返回上一页”。

**可借鉴点（分析）**：减少手动操作，适合明确而短的语音指令。

## 输入、操作与输出

语音转写 → Jev 判断要执行的操作 → 浏览器执行。

没有披露的提示词、状态格式、阈值或失败恢复逻辑保持未知。应用按作者演示收录，不认定已稳定上线。
