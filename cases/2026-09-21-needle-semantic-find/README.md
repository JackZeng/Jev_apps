## 应用场景与价值

记不清关键词时，用自己的话找到网页里的相关句子。

**可借鉴点（分析）**：比关键词查找更能处理同义表达，结果仍可回到原文核对。

## 输入、操作与输出

扩展提取段落，后端经 Vercel AI Gateway 让 Jev 判断相关性并选择句子，再映射回页面高亮；0.58 为收录阈值。

没有披露的提示词、状态格式、阈值或失败恢复逻辑保持未知。应用按作者演示收录，不认定已稳定上线。
