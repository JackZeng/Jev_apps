## 用人话解释原理

不是把所有历史重写成一篇摘要，而是先给工具记录评相关性，再选择保留哪些。省下空间的同时，也可能丢掉以后才需要的信息。

## 应用场景与价值

给 AI 助手的工作记录瘦身，只把眼下有用的内容继续带着。

**可借鉴点（分析）**：通过筛选减少上下文，不必把整段历史重写成摘要。

## 输入、操作与输出

按源码版本 e3f262a：配对工具调用与结果，保护首条及最近消息，将对话压进状态预算；工具输出正文替换为结果状态和长度。Jev 分别判断是否保留调用及结果，程序据阈值保留、截断或删除。Claude Code hook 在报错或压缩不足时退回内置摘要。

没有披露的提示词、状态格式、阈值或失败恢复逻辑保持未知。应用按作者演示收录，不认定已稳定上线。
