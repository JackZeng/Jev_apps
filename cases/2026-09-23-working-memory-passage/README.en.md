## Use and value

Highlight concepts and relationships instructional prose may require a reader to retain together.

**Useful aspect (analysis):** Source locations and manual grouping review are more actionable than one difficulty score for a whole passage.

## Inputs, steps and outputs

A local parser defines reading steps; Jev judges familiarity, active concepts, grouping and relationships. Code totals proposed units against a selected budget.

Undisclosed prompts, state formats, thresholds and recovery logic remain unknown. Inclusion of a demo does not establish a stable release.
