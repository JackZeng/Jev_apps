## 应用场景与价值

标出一段教学文字可能让读者同时记住的概念与关系。

**可借鉴点（分析）**：提供原文定位和人工调整，比只给整篇难度分更便于修改教材。

## 输入、操作与输出

本地解析阅读步骤，Jev 判断熟悉度、活跃概念、分组与关系；程序累计建议的认知单位并与选定预算比较。

没有披露的提示词、状态格式、阈值或失败恢复逻辑保持未知。应用按作者演示收录，不认定已稳定上线。
