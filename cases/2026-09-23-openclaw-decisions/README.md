## 应用场景与价值

让插件或程序直接请求分类、评分和选择，供后续流程使用。

**可借鉴点（分析）**：统一插件接口，方便把判断接进现有工作流，不必全由聊天模型逐项发起。

## 输入、操作与输出

官方说明 Plugin SDK 暴露 api.runtime.decisions.evaluate，由配置的决策模型处理；此前让代理调用决策工具，现在应用代码也可直接调用。

没有披露的提示词、状态格式、阈值或失败恢复逻辑保持未知。应用按作者演示收录，不认定已稳定上线。
