# Images and attachments

[简体中文](README.md) | **English**

Use one directory per case: `assets/YYYY-MM-DD-short-slug/`. Prefer short, readable filenames such as `workflow.png` or `result.jpg`.

Add a `SOURCES.md` in each asset directory:

| Filename | Original source URL | Author | Permission / license basis | Retrieved |
| --- | --- | --- | --- | --- |

Prefer public source links. Commit only small attachments you have the right to publish, ideally below 10 MB each. Link large videos, models and raw material externally, or configure large-file storage when needed.

From case pages, use `../../assets/<case-id>/<filename>`; from analysis pages, use `../assets/<case-id>/<filename>`.
