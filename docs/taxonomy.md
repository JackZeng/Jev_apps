# 分类与状态约定

以下是整理内容的分类，不表示 Jev 已经支持相应能力。只有出现实际材料后才按需使用或扩展分类。

## 应用分类

每个案例选择一个主要分类，其他特点使用标签表达。

| 分类 | 适用内容 |
| --- | --- |
| 效率与自动化 | 工作流、重复操作、个人效率 |
| 内容创作 | 文字、图像、音频、视频等创作 |
| 开发与工具 | 编程、调试、应用与工具制作 |
| 数据与研究 | 信息检索、资料整理、数据分析 |
| 交互与体验 | 实时交互、界面、演示体验 |
| 学习与教育 | 教学、练习、知识讲解 |
| 其他 | 暂不适合现有分类的案例 |

标签自由添加，优先复用已有写法；建议 2–5 个，描述任务、输入输出或技术特点。平台可记录 X、YouTube、Reddit、TikTok、小红书、抖音、Bilibili、公众号等，以实际来源为准。

## 验证状态

| 状态 | 含义 |
| --- | --- |
| 未复现 | 仅完成收录或阅读，没有实际运行 |
| 复现中 | 正在实际尝试，尚无最终结果 |
| 部分复现 | 部分效果已验证，需说明缺失部分 |
| 已复现 | 在记录的环境与步骤下达到明确的预期结果 |
| 复现失败 | 实际尝试未成功，需记录环境、步骤与错误 |

验证状态反映复现结果。另设“可用性”字段记录 `未知`、`可用`、`受限` 或 `已失效`，避免把链接失效与实验失败混为一谈。

## 日期与证据

- 日期统一为 `YYYY-MM-DD`；精确到时间时注明时区。
- **原帖发布日期**：原作者发布内容的日期，无法确认写“未知”。
- **收录日期**：内容进入仓库的日期，也是条目路径使用的日期。
- **最后更新**：本篇记录最近编辑的日期。
- **最后复查**：最近实际检查来源、功能或复现结果的日期；未检查写“未复查”。
- **官方说明 / 作者陈述**：注明链接及相关位置；作者的说法不自动等于已验证事实。
- **实际观察 / 复现实验**：写明观察范围、环境和证据。
- **技术推测**：说明推测依据和需要进一步验证的问题。
