# 分类与状态约定

**简体中文** | [English](taxonomy.en.md)

当前主线是 X 上 TypeSafe Jev 的应用。每条选择一个主类别，同项目不重复计数；不同实现按相同用途放在一起。

## 应用分类

| 分组 ID | 分类 | 适用内容 |
| --- | --- | --- |
| browser | 浏览器与电脑操作 | DOM、无障碍树、OCR、桌面执行、语音操作与应用 QA |
| routing | 模型、技能与工具路由 | 选择模型、harness、技能和工具，及通用接入层 |
| review | 代码质量与安全检查 | PR、代码质量、命令风险、提示预筛与资料上传判断 |
| data | 数据分类与信息整理 | 邮件、论文、表格、银行描述与客服意图 |
| content | 内容与广告分析 | 写作反馈、历史内容复盘、传播实验、广告和言论分析 |
| filter | 网页与信息流过滤 | 语义内容屏蔽与网页元素清理 |
| memory | 上下文与记忆筛选 | 当前会话压缩和外部记忆相关性筛选 |
| games | 游戏决策与求解 | 马里奥、棋类、卡牌、动作游戏、魔方等 |
| simulation | NPC、驾驶与群体模拟 | 虚拟角色、车辆控制、无人机、合成人物与叙事 |
| interaction | 实时交互与组合实验 | 实时感知、判断交互、字符或像素组合与计算实验 |
| finance | 交易与历史回测 | 行情决策、订单执行与历史策略实验；不据演示推断收益 |

更细的重复功能在类别内部相邻排列，例如多个马里奥实现、多个模型路由器。类别总数与条目数由生成器从目录统计。没有同类样本时明确说明无法对比。

## 正式收录门槛

主帖取数时点赞 ≥ 200，有原始来源、明确应用和对应图片/视频。数字保留时间快照，不合计转载或补充帖；初筛符合门槛但缺证据的进入待整理区。点赞反映关注度，不代表技术有效性。

## 验证状态

| 状态 | 含义 |
| --- | --- |
| 未复现 | 仅完成收录或阅读，没有实际运行 |
| 复现中 | 正在实际尝试，尚无最终结果 |
| 部分复现 | 部分效果已验证，需说明缺失部分 |
| 已复现 | 在记录的环境与步骤下达到明确的预期结果 |
| 复现失败 | 实际尝试未成功，需记录环境、步骤与错误 |

验证状态反映复现结果。另设“可用性”字段记录 `未知`、`可用`、`受限` 或 `已失效`，避免把链接失效与实验失败混为一谈。

## 日期与证据

- 日期统一为 `YYYY-MM-DD`；精确到时间时注明时区。
- **原帖发布日期**：原作者发布内容的日期，无法确认写“未知”。
- **收录日期**：内容进入仓库的日期，也是条目路径使用的日期。
- **最后更新**：本篇记录最近编辑的日期。
- **最后复查**：最近实际检查来源、功能或复现结果的日期；未检查写“未复查”。
- **官方说明 / 作者陈述**：注明链接及相关位置；作者的说法不自动等于已验证事实。
- **实际观察 / 复现实验**：写明观察范围、环境和证据。
- **技术推测**：说明推测依据和需要进一步验证的问题。
