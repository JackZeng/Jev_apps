# Context and memory filtering: how they work and compare

[简体中文](2026-09-18-memory.md) | **English**

Collected / source-reviewed: 2026-09-18. Status: **not independently reproduced**.

## Choosing an approach

Tool-history compaction filters the current conversation; memory retrieval filtering selects from an external memory store. Both reduce input at different stages. Evaluate retained information and task quality before comparing token reductions.

## Individual comparisons

These are analytical strengths and limitations based on public descriptions, not controlled experimental findings.

| Example | Strengths / suitable uses | Limitations / missing evidence |
| --- | --- | --- |
| [Tool-history context compaction](../cases/2026-09-18-context-compaction/README.en.md) | Reduces context through selection without rewriting the entire history as a summary. | No long-task retention evaluation; discarded records may be needed later. |
| [Memory retrieval filtering](../cases/2026-09-18-memory-retrieval/README.en.md) | A post-retrieval filter that can complement existing memory systems. | Explicitly a quick test, without recall or long-task accuracy data. |

## Workflow and mechanism

History or memory candidates plus current task → Jev relevance scores → select records → construct downstream context.

Selecting original text and generating a new summary have different failure modes: selection can omit information needed later, while rewriting can distort it. The reported 94% reduction is one quick test, not a default compression target.

Individual input and implementation differences are documented in the linked cases. This is an application-level synthesis, not a claim that every implementation is identical or an account of Jev’s internal training architecture.

## Suggested reproduction experiments

Test delayed information needs, error recovery, old-decision tracing and cross-turn references in long tasks. Track recall, completion quality, filtering overhead and total tokens while retaining recoverable originals.
