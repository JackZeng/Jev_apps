# NPC、驾驶与群体模拟：原理与对比

**简体中文** | [English](2026-09-18-simulation.en.md)

首次整理：2026-09-18；各案例来源复查时间见详情。验证状态：**未复现**。

## 选择建议

NPC 需求选择适合研究角色行为，500 agents 演示关注并发吞吐。驾驶原型中，不暂停的模拟器更明确暴露延迟约束；无人机原型有代码线索。小镇与虚构 personas 属于叙事和构思工具，不能据合成人物反应预测真实世界。 新增交通灯、双臂机器人和生命体征模拟：分别选择放行方向、分层动作和状态标签。机器人明确把 IK/物理留给代码；交通的 600% 和监测的实际可用性缺对应验证。应按各自任务评测，不把所有模拟都当成现实部署。 搬苹果对照公开单次试验轨迹与物理判据，可检查性强于仅有短片，但不是成功率统计。其回放删去了 API 等待，需看 wall time，不能用视频长度比较速度。

| [Unstable Government 小镇](../cases/2026-09-18-unstable-government/README.md) | 生成叙事与居民选择分工明确，适合互动故事。 | 角色反应是虚构模拟，不能作为社会政策影响预测。 |

| [Jev City · 九路口交通灯模拟](../cases/2026-09-19-traffic-light-city/README.md) | 相比驾驶模拟中控制一辆车，本例协调路口放行，便于探索多处决策对拥堵的影响。 | 缺少同等车流、随机种子、多次运行与固定/自适应规则基线；虚拟路网结果不能直接外推真实城市。 |
| [生命体征模拟 · 状态变化判断](../cases/2026-09-19-vital-signs-simulator/README.md) | 相对交通与机器人仿真，本例探讨状态判别和误报；场景设置可帮助提出后续评测问题。 | 未见临床数据、独立验证或漏报统计；演示不能支持部署到实际患者监测。作者将校准解释为重复回答稳定，也未建立风险概率的有效性。 |
| [双臂机器人仿真 · 分层动作决策](../cases/2026-09-19-dual-arm-robot-sim/README.md) | 与无人机仿真同样分离决策和运动计算，但任务变成双臂操作与物体选择，便于研究分层控制。 | 没有真实机器人运行证据或完整成功率评估；约 500ms 的响应不能当作关节控制周期或全部任务时长。 |
| [MuJoCo · 三模型搬苹果对照](../cases/2026-09-20-mujoco-apple-control/README.md) | 相较双臂积木短片，公开了响应记录、轨迹、源代码快照、成功判据和离线校验入口，便于后续复核。 | 每控制器仅一个 seed-0 试验；不能估计成功率。回放按模拟时间同步并去掉 API 等待，不能把视频长度当实际完成时间。 |

## 可观察流程与机制

模拟状态与角色目标 → Jev 决策 → 仿真执行 → 更新状态；叙事场景可由 LLM 提供候选反应。

驾驶视频中的“FSD”是原作者命名，不是对 Tesla 产品或实车能力的复现认定。群体演示的总 API 吞吐必须与单角色更新频率分开。虚构用户的采用意向不能代替实际访谈或实验。 无人机仓库明确了 MuJoCo 仿真与高频控制/低频模型决策的分层，并主动披露了单次成功对照的限制。

各案例的输入和实现差异见上表链接的来源记录。该流程是应用层归纳，不代表每个项目都采用完全相同的实现，也不是对 Jev 内部训练架构的推断。

## 复现实验建议

公开环境、状态更新频率、暂停策略、网络抖动及失败定义；长期统计碰撞、任务成功和单角色行为一致性。合成用户实验应再与真实调查结果对照。

**尚未执行实验。** 当前没有本仓库产生的耗时、准确率或成本结果。
