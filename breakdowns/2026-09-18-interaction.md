# 实时交互与组合实验：原理与对比

**简体中文** | [English](2026-09-18-interaction.en.md)

首次整理：2026-09-18；各案例来源复查时间见详情。验证状态：**未复现**。

## 选择建议

TypeGPU 案例把本地感知与远端语义判断结合；Ask Jev 提供简单判断界面；词表和字符聊天展示选择循环；像素绘图与 RISC-jeV 展示将大量小判断组合成输出。这些适合作为机制启发，不应直接当成替代专用模型或程序的产品。 启动器、emoji 候选、导购和语音指向画布，分别面向文件选择、表达辅助、购物对话和对象操作；用途不同，保留独立条目。画布与 TypeGPU 都组合本地感知，但前者操作对象，后者改变视听特效。 Probably 则把判断、分支和文字生成组织成小语言；官网是预录回放，比较实时性时需与真正的本地模型调用区分。 终端历史补全和启动器都是从候选中选下一步：前者可查固定版本文档和门槛逻辑，但只用虚构历史演示；后者侧重文件选择。比较时分开看命中率、接受率和执行风险。 json-render 从组件目录组合可交互界面，颜色实验从 16 色候选给视觉反馈，CNVS 判断一句话是否值得响应。三者分别需要检查结构与语义、主观匹配、误触发，不能只比较响应速度。 会议流程图组合 Jev 筛选、LLM 整理与画图代码；试衣组合服装选择与视频处理；剪贴板选择已有文本；加拿大地图展示词语联想。比较时分别看漏记、选衣准确性、粘贴命中率与主观关联，分开计算外围处理成本。 Toothless 与 CNVS 都判断何时响应，需比较误唤醒和漏唤醒；大声读只评转录后的文字，不替代声学发音评分；AnimeAct 负责角色反馈，Jev 接口细节仍待补。Token、词和字符循环应比较整段质量与调用量，不能只看单步速度。 演讲教练对照提纲追踪覆盖，会议转流程图整理讨论结构；前者尚是本地原型，重点看漏提醒和误提醒，不能混同为已发布的实时会议助手。 轮次结束检测决定何时接话，半句选工具决定是否可提前行动；预测键盘只给输入提示，Mutuals 控制角色反馈。自然语言解释器把流程交给代码，不等于证明模型能或不能推理。

## 同类逐项对比

以下优势和限制是基于作者公开说明的技术分析；不构成同条件实验结论。

| 案例 | 相对优势 / 适用场景 | 限制 / 尚缺证据 |
| --- | --- | --- |
| [TypeGPU 实时语义特效](../cases/2026-09-18-typegpu-realtime/README.md) | 将本地感知与语义决策分离，适合实时交互媒体。 | 整个流水线不只包含 Jev；没有端到端延迟和各模块消融结果。 |
| [Ask Jev](../cases/2026-09-18-ask-jev/README.md) | 有公开体验入口，直观认识判断模型的输出形式。 | 娱乐和产品交互示例，不能将任意判断当成可靠知识回答。 |
| [有限词表聊天](../cases/2026-09-18-word-chat/README.md) | 展示如何用选择能力组合出生成式交互。 | 词表限制表达；每词一次决策的耗时与成本不适合直接类比文本模型。 |
| [29 选项字符生成](../cases/2026-09-18-character-chat/README.md) | 控制循环明确，比有限词表更自由。 | 字符循环调用次数大；不证明模型原生具备文本生成 API。 |
| [并行像素绘图](../cases/2026-09-18-pixel-drawing/README.md) | 把分类输出组合成视觉结果，具有原理探索价值。 | 不是已验证的通用图像生成器；品质、分辨率和总成本未知。 |
| [RISC-jeV 逻辑门实验](../cases/2026-09-18-riscv/README.md) | 提供明确的组合层次，适合理解“决策如何构成计算”。 | 概念实验，不是计算效率优势；确定性代码完成逻辑运算更合适。 |
| [意图预测启动器](../cases/2026-09-18-predictive-launcher/README.md) | 相比按文件名或别名匹配，尝试处理“刚下载”等带情境的表达；适合小范围文件候选选择。 | 约 100ms 来自作者陈述；缺少文件规模、重名文件和模糊指代测试。模型高置信度不等于一定找对文件。 |
| [实时电商导购与头像表情](../cases/2026-09-18-live-commerce-assistant/README.md) | 将推荐放进实时对话，适合探索边说边选的购物体验；比离线意图标签更接近面向顾客的交互。 | 只是简易演示；没有推荐相关性、库存一致性或端到端延迟评估。表情映射是演示设计，不能推断为 Jev 独有能力。 |
| [实时表情候选](../cases/2026-09-18-emoji-suggestions/README.md) | 输出范围有限、容易展示；相比字符聊天的长循环，更适合把一次判断直接变成界面反馈。 | 100–200ms 及候选数不影响速度是该演示的作者报告，不能推广到任意规模；缺少语言、语境歧义及表情准确率评估。 |
| [语音与手指指向控制画布](../cases/2026-09-18-voice-gesture-canvas/README.md) | 把自然语言与指向结合，补足“那个”“那里”在纯文字指令里的歧义；与 TypeGPU 的语义特效相比，关注画布对象操作。 | 作者明确表示并不完美，仍是可行性探索；没有指向误差、语音错识或操作成功率数据。多个小判断一致性仍需校验。 |
| [Probably · 用语义判断控制程序](../cases/2026-09-18-probably-language/README.md) | 把分类、分支和改写循环放进可读的小语言，方便理解 Jev 与生成模型怎样协作；可与词表聊天、RISC-jeV 的组合实验对照。 | 作者明确是玩具语言；没有数组、函数等通用语言能力。官网托管演示仅播放预录结果，任意自定义程序要在本地连接真实模型运行；不能用页面回放速度当成推理性能。 |
| [终端历史命令 · 语义补全](../cases/2026-09-18-shell-history-suggestions/README.md) | 比字面前缀补全更能处理描述意图的输入，又将结果限制在历史候选里；与预测性启动器一样做候选选择，但对象是命令而非文件。 | 历史命令可能过时或带敏感内容，并会作为候选发给服务端。选择正确不代表执行安全；仍需用户检查。README 报告请求约 0.7–0.9 秒，不能套用其他演示的毫秒宣传。作者明确是实验，不是其日常使用证明。 |
| [json-render · 用组件选择拼出界面](../cases/2026-09-19-json-render-ui/README.md) | 比逐字符输出更容易约束结构；相对像素绘图，输出可交互的组件树，结构错误可由代码拦截。 | 文档限制单批新增 14 个元素、每请求 14 次评估、最大深度 4；结构合法不保证内容正确或设计好看。 |
| [CNVS · 无唤醒词语音指令门控](../cases/2026-09-19-cnvs-voice-gate/README.md) | 相对语音加手势画布，本例聚焦是否响应这一步，不要求用户先说固定口令。 | 误触发、漏触发、录音处理和端到端延迟缺少评测；不能把文本判断模型写成直接理解原始音频。 |
| [词语与颜色 · 16 色概率可视化](../cases/2026-09-19-color-judgments/README.md) | 相比逐像素绘图，候选更小、语义反馈直观，适合研究词语与视觉反馈的关系。 | 受限于调色板与提示，主观颜色联想没有统一正确答案；不是图像识别或色彩科学准确性评测。 |
| [会议转流程图 · 边聊边整理业务](../cases/2026-09-20-meeting-flowchart/README.md) | 比单纯给访谈记录打分更直接地产生可修改的工作草稿；判断、文字整理和画图职责清楚。 | 50% 是作者设定的门槛，不是正确率保证；缺完整转录、漏记统计和与人工流程图的对照。 |
| [Drape 试衣实验 · 听要求选衣服](../cases/2026-09-20-drape-outfit-selection/README.md) | 比通用商品推荐更强调连续对话和当前穿搭，选择结果有直观反馈。 | 没有披露完整视频模型、转录链路或端到端账单；不能把单次选衣服的速度与费用当成完整试衣成本。 |
| [加拿大词语地图 · 把联想画在地图上](../cases/2026-09-20-canada-word-map/README.md) | 与词语选颜色一样适合直观展示语义判断，但输出变成地理区域。 | 主观联想不能当人口、文化或地域事实；没有标准答案集或校准验证。 |

## 可观察流程与机制

准备有限候选或原子问题 → Jev 判定 → 程序组合结果 → 更新交互状态或输出。

词表聊天与字符聊天都由程序把单步选择拼接成文本；这不改变 API 的判断式输出性质。RISC-jeV 中逻辑门和指令解释层叠加，展示可组合性，不意味着用模型算逻辑门更高效。

各案例的输入和实现差异见上表链接的来源记录。该流程是应用层归纳，不代表每个项目都采用完全相同的实现，也不是对 Jev 内部训练架构的推断。

## 复现实验建议

记录候选规模、分辨率或字符数、循环次数和全程费用；与确定性代码或专用生成模型比较输出质量。感知流水线需分开测本地模型、网络决策及渲染延迟。
