# Model, skill and tool routing: how they work and compare

[简体中文](2026-09-18-routing.md) | **English**

First compiled: 2026-09-18; see each case for its source-review date. Status: **not independently reproduced**.

## Choosing an approach

Eve and Ephraim demonstrate model selection; Firstmate and local delegation address agent orchestration. Skillbox searches a skill library, Coding Garden connects everyday tools, and the Eve tool agent substitutes one stage of an existing system. ai-cli is an integration interface. These approaches can be combined. Hono JevRouter selects HTTP handlers using descriptions and the first qualifying route in registration order. Unlike model or skill selection, a routing error changes the response directly; it must not replace authentication. Codex Model Router selects a model and reasoning configuration each turn with documented fallback, but a user observed over-routing on easy tasks. Compare final quality, cache behavior and total bills, not classification speed alone. The Claude Code Mod defaults to subagent-model and main-effort routing, leaving main-model switching off. Compare cache effects, fallback and final quality separately from the Codex per-turn router. Astra-Ares adjusts one model’s effort between generations; OpenClaw exposes a shared plugin interface. Compare full-task quality, cost and cache hits for the former, and separate development interfaces from proposed uses for the latter. The workflow builder connects nodes, AgentRun learns repeatable procedures and Monid connects tools; they do more than model selection. Prompt Box adds machine/folder routing and Corent workload thresholds; compare misrouting and fallback quality.

| [Codex Model Router: choose a model each turn](../cases/2026-09-19-codex-model-router/README.en.md) | Embeds routing specifically in Codex with documented policies. Repository replay savings are not this user’s measured savings. |
| [Claude Code Mod: model and effort routing](../cases/2026-09-19-claude-code-jev-router/README.en.md) | Unlike the Codex router, this uses Claude Code hooks and separates main-session and subagent decisions, making cache and fallback policies inspectable. | No complete quality, cache-cost or savings comparison. Without a Jev key, the host classifier is used, so that path is not evidence of Jev performance. |
| [Astra-Ares: adjust reasoning effort as work progresses](../cases/2026-09-23-astra-ares/README.en.md) | Finer control than choosing a model once per task, with inspectable switching conditions and context boundaries. | An early preview requiring a patched CLI, not intervention inside one generation. Validation explicitly excludes workload savings and cache hit rates; halving cost is not guaranteed. |
| [OpenClaw: a shared decision interface for plugins](../cases/2026-09-23-openclaw-decisions/README.en.md) | A common plugin interface makes decisions reusable without requiring a chat model to initiate every judgment. | Available in development checkouts; provider packages await a supporting release. Voice gating, tool filtering, compaction and routing are largely explorations or proposals, not all shipped features. |
| [Jev Workflow Builder: connect decisions into a workflow](../cases/2026-09-23-jev-workflow-builder/README.en.md) | Run previews and REST access make multi-step support-routing experiments easier to inspect. | Without a key, code explicitly returns keyword-based mock results, not Jev inference. Production concurrency and reliability are untested. |
| [AgentRun: turn repeated work into reusable procedures](../cases/2026-09-23-agentrun/README.en.md) | Separates research, decisions and execution so avoided work can be inspected. | Comparisons concern the author’s compliance-alert workload, without complete public cases or independent audit. Skipping research can miss evidence; cost alone is insufficient. |
| [Monid: add batch decisions to tool workflows](../cases/2026-09-23-monid-jev-tools/README.en.md) | Focuses on batch processing after tools retrieve data, rather than only model selection. | 2,000 describes the tool catalog, not verified task coverage. ## Workflow and mechanism

Task text and candidate capabilities → Jev choice or scores → application checks candidates and constraints → invoke the selected model, skill or tool.

Routing reduces the overhead of choosing an executor; the executor still does the work. Firstmate reports a small 25-task agreement study. Skillbox lacks retrieval-recall data. Deterministic invocation does not guarantee correct choices.

Individual input and implementation differences are documented in the linked cases. This is an application-level synthesis, not a claim that every implementation is identical or an account of Jev’s internal training architecture.

## Suggested reproduction experiments
